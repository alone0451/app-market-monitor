# 应用发布监测（App 市场版本巡检工具）

一个**本地运行**的 Android 与 iOS 应用市场版本巡检工具，用于持续核对公司 App 在
主流应用市场中的版本、发布时间、开发者和运营主体，及时发现**版本不一致、
非授权发布、同名错包和疑似仿冒应用**等问题。

所有配置、数据库、截图和安装包默认只保存在本机，不会上传到任何服务器；
Git 也会忽略这些运行数据，发布到公开仓库的只有程序代码。

## 这个程序是做什么的

很多公司在多个市场发布同一个 App，容易出现这几类问题：

- 某个市场漏更新，版本落后于其他渠道；
- App 被第三方/灰产渠道私自上架，用户下载到来源不明的安装包；
- 出现与公司 App 同名但包名不同的仿冒应用；
- 同一 App 在不同市场的运营主体、开发者信息不一致。

本工具把这些问题变成**可巡检、可留证、可复查**的流程：按市场逐个读取官方页面或
手机端详情，记录版本、发布时间、公司主体，并给出风险结论和现场截图证据。

## 核心功能

- **候选发现**：按 App 名称或公司名称在支持的市场中搜索候选，核对包名后建立监测对象。
- **版本巡检**：遍历「启用渠道 × 监测对象」，采集版本号、发布时间、开发者/运营主体。
- **风险识别**：
  - 同平台渠道版本不一致 → 提醒；
  - 非授权发布渠道检测到该应用版本 → 高风险（未发现该应用则不构成风险）；
  - 同名应用包名不一致 → 严重（疑似仿冒或错误条目）；
  - 安装包下载后自动校验包名、版本、SHA-256 与签名，高风险包不提供下载。
  - 安装包获取：报表按渠道结果只展示真实可用操作；有官方网页直链时支持 4 路分段下载和断点续传，无直链时仅在实体手机已安装目标应用后提供 APK 提取与校验。
- **证据留痕**：网页巡检保留来源 URL；手机端复核保留截图；失败原因与状态分别记录，
  不会把“无法采集”误报为“未发布”。
- **历史对比**：Android 与 iOS 独立建档、独立比较版本；报表可查看版本变化与监测时间。

## 哪些市场需要实体手机

**OPPO、vivo、荣耀**三个市场没有稳定公开的网页数据源，需要连接 Android 实体手机，
在手机端的官方市场客户端里打开应用详情并截图留证。

前置条件：

1. 在手机中开启“开发者选项”和“USB 调试”；
2. 使用支持数据传输的 USB 线连接 Mac；
3. 在手机弹窗中允许这台电脑进行 USB 调试；
4. 在手机上安装对应的官方市场客户端：
   - OPPO 软件商店（`com.heytap.market`）
   - vivo 应用商店（`com.bbk.appstore`）
   - 荣耀应用市场（`com.hihonor.appmarket`）
5. 打开“监测配置 → USB 手机渠道复核”，点击“检测手机与市场客户端”，确认手机和客户端都被识别。

手机端**只读取详情和截图，不会自动搜索、下载或安装目标 App**；遇到登录、隐私协议、
验证码或无法解析的页面时，系统会停止自动操作并保留截图，等待人工处理。
不同厂商、客户端版本的页面结构可能变化，请先完成一次“检测手机与市场客户端”确认兼容。

## macOS 一键启动

要求：

- macOS；
- Python 3.10 或更高版本；
- 能访问 Python 软件源和 Google 官方 Android 工具下载地址。

终端运行：

```bash
cd app-market-monitor
./start.sh
```

也可以在 Finder 中双击 `start.command`。

首次启动会自动：

1. 创建项目独立的 `.venv`；
2. 安装网页巡检、APK 解析和中文搜索依赖；
3. 将 Google 官方 Android Platform-Tools 下载到项目的 `.tools` 目录；
4. 输出部署与手机兼容性诊断；
5. 在 `http://127.0.0.1:5001` 启动系统。

Platform-Tools 使用 Google 官方长期下载地址，不依赖 Android Studio 或其他本地项目；
macOS 连接 Android 实体设备通常不需要额外 USB 驱动。

应用宝手机截图识别可选依赖 Tesseract 与简体中文语言包：

```bash
brew install tesseract tesseract-lang
```

缺少 OCR 不影响网页巡检。

## 日常使用流程

1. 打开 [http://127.0.0.1:5001](http://127.0.0.1:5001)；
2. 在“监测配置”中按 App 名称或公司名称搜索候选，核对包名后加入监测清单；
3. 在“监测哪些应用市场”中勾选要巡检的市场（支持“本次全选 / 本次清空”）；
4. 为渠道维护“发布标记”（官方 / 非授权 / 未知），非授权渠道会影响风险结论；
5. 点击“开始巡检”，等待完成后查看报表；
6. 报表中可查看每个市场的版本、发布时间、公司主体、风险结论和现场截图；个别渠道失败时可点击该行“单独重试”；
7. OPPO、vivo、荣耀等手机渠道查询前请保持手机亮屏并解锁；系统可以唤醒休眠屏幕，但不会输入密码或绕过锁屏。

## 风险结论怎么读

- **版本不一致**：同平台某渠道版本低于最新版本 → “提醒”，可能是发布延迟或异常旧版本；
- **非授权渠道 + 发现应用版本** → “高风险”，疑似未授权发布，需核验主体和签名；
- **非授权渠道 + 未发现应用** → 不构成风险；
- **同名错包（包名不一致）** → “严重”，疑似仿冒或错误条目；
- **安装包校验失败**（包名/版本/SHA-256/签名不一致）→ “严重”，不提供下载。

## 安全边界

- 仅监测自有或已获授权的 App，并遵守各市场服务条款和访问频率限制。
- 不自动接受隐私协议、权限申请或登录授权。
- 不自动绕过验证码、滑块、设备完整性校验或厂商限制。
- 不把名称相似当成包名一致；发现包名不一致时按高风险展示。
- 安装包签名比单一文件哈希更适合用于判断跨版本官方身份。
- 从手机提取安装包仅做读取和校验，不自动安装、不自动点击市场下载。
- 运行数据（数据库、截图、安装包、配置）默认不离开本机，也不进入 Git 仓库。
